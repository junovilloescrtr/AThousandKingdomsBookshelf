# A Thousand Kingdoms — Bookshelf

## Sobre el proyecto

Descripción general del mundo y de la obra.

## Estructura

- 01_WORLD → Información general del mundo
- 02_CHARACTERS → Personajes
- 03_FACTIONS → Casas, organizaciones y grupos
- 04_LOCATIONS → Lugares
- 05_TIMELINE → Cronología
- 06_RELATIONSHIPS → Relaciones entre personajes
- 07_CHRONICLES → Historia narrada del mundo
- 08_CHAPTERS → Novela
- 09_REFERENCE → Información auxiliar
- 99_ARCHIVE → Material antiguo/no vigente

## Regla fundamental

Los documentos de referencia constituyen la información canónica del mundo.

Los capítulos constituyen la narración de los acontecimientos.

Cuando exista una contradicción preguntar.
